# Personal Portfolio Website

## About the Website

This is my personal portfolio website created as part of the Web Programming Phase 1 assignment.

The website presents my profile, education, technical skills, projects, activities and contact information.

## Website Structure

The website contains the following sections:

- Home
- Profile
- Curriculum Vitae
- Education & Technical Expertise
- Projects
- Activities / Gallery
- Contact

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Media Queries
- HTML5 Forms
- HTML5 Tables
- iframe

## Design Description

The website uses a pink and white professional design with rounded cards, soft shadows and pink gradient elements.

The navigation bar allows users to move between different sections of the portfolio.

Flexbox and CSS Grid are used for layout, while media queries make the website responsive on different screen sizes.
